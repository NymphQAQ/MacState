# 文件类型统计与大文件

用户要求：九类统计（视频、图片、音频、文档、压缩包、应用、开发文件、模型文件、其他）、完整最大文件排行、大小/类型/修改时间筛选、大小排序、Finder、复制路径、移到废纸篓；不运行测试。

设计：复用唯一元数据索引。分类规则为可修改的 SQL 表达式，不覆盖原始 kind 或新增全盘扫描，开发/模型扩展名优先于通用文本/其他，App 包内文件归入应用，目录元数据单列避免虚构分类。统计提供数量、物理占用和逻辑大小。全卷大文件每页 100 项加一条判断下一页，不执行全量 COUNT；提供逻辑/物理口径切换及排序，最小/最大大小、分类、修改日期区间。共享查询可取消，刷新快照按需进行。

界面：延续玻璃卡片，Avenir Next / PingFang SC；蓝 #5aa9ff、绿 #32d74b、橙 #ffb340、红 #ff7b72。分类卡片按占用排行，点击进入相应大文件列表。大文件顶部一排可换行筛选，主体有界滚动列表与固定分页。每行 Finder/复制/废纸篓操作。

安全：废纸篓操作只接受当前卷索引内的本地普通文件/链接，禁止系统路径和 App 包内部；原生确认列出具体路径与大小，再核对设备/inode/大小/修改时间后移入废纸篓。失败明确提示，不永久删除、不申请权限、不批量隐式清理。成功标记父目录待更新并刷新视图。
