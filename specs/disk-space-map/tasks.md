# 空间地图

用户要求：Treemap 磁盘空间地图、文件夹/文件类型可视化、目录层级浏览、上一级、Finder 定位；不运行测试。

设计：分析页新增独立入口。复用统一 SQLite 元数据索引、只读连接和快照；目录视图按实际物理占用查询最大的 256 个直接子项，剩余项目及目录元数据汇总成独立块，避免分页造成面积遗漏。类型视图按当前目录全部后代文件聚合，目录自身分配空间单独表示，硬链接沿用索引去重结果。不读取文件内容或新建扫描器。

界面：延续玻璃卡片，Avenir Next / PingFang SC；蓝 #5aa9ff 为目录，绿 #32d74b 为图像，橙 #ffb340 为视频，红 #ff7b72 为音频。地图占左侧主要面积，右侧窄栏显示选择与图例；窄窗口上下排列。Squarified Treemap 面积与索引物理占用成比例；零占用项可在图例选择。双击目录或选择后点进入，面包屑与上一级浏览，选择后 Finder 定位。类型块为聚合不提供虚假文件路径。

地图为按需读取的索引快照，提供刷新按钮；更新不自动重排正在操作的地图。类型聚合需遍历当前范围的索引记录，大卷可能需要等待，可退出或切换取消。APFS 共享块/快照/不可访问内容不计入地图，不能当作卷容量或可释放空间。
