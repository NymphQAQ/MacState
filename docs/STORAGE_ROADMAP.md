## 共用数据基础与约束

- 索引只收集文件关键信息，不读文件内容；本地目录扫描策略及权限限制保持不变。
- 保留名称、路径、后缀、类型、逻辑大小、实际分配大小、创建/修改时间、设备/inode/硬链接、目录聚合、扫描受限状态。
- 文件 ID 是数据库内部标识；移动/删除重建后可能变化，历史不可只依赖该 ID，需结合卷标识与路径/文件身份。
- 大文件、Treemap、分类、应用/开发工具/缓存归属复用统一索引；规则可更新，不将分析结果永久硬编码进文件类型。

- 重复文件哈希、媒体分辨率、设备备份信息及快照信息按需补充；元数据相同不代表内容重复。
- 清理采用独立规则、风险分级、预览、保护和确认，最终移到废纸篓；本次不新增自动删除。
