# Traditional color names

Bundled color-name and hexadecimal pairs are sourced from the canonical list in [nevertoday/zhongguo-traditional-colors](https://github.com/nevertoday/zhongguo-traditional-colors/blob/main/docs/chinese-color-master-list.md). The list contains 742 colors and is distributed under GPL-3.0; see `LICENSE`.

MacState uses these values only to display the nearest traditional color name for a sampled pixel. The match is approximate; the displayed sampled HEX/RGB values remain exact.
