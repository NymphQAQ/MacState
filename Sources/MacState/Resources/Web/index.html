统计说明与保存位置

点击应用行可展开主进程及全部已记录的辅助进程，包括已退出的进程。每个进程保留平均估算功耗、累计耗能与有效读数覆盖率；相同 PID 的不同启动实例分别记录。各进程按自己的有效区间平均，平均值不能直接相加。旧记录未采集的进程明细无法补齐。

应用合计功耗 = CPU 内核能量增量 + GPU 设备能量按实际执行时间归属的份额，再除以采样秒数。GPU 总能量由 IOReport 读取，已经反映频率变化；执行时间来自 IOGPU AppUsage，包括受保护进程的 GPU 客户端，不使用前台时长或提交次数。合并主进程与可归属辅助进程，包含后台运行，界面保留一列功耗。GPU 时间比例不能区分不同任务的能耗强度，因此仍为估算，不能保证完整应用实测准确。

平均功耗按有效采样时长加权；累计 Wh 由原始能量增量计算，不使用平滑值积分。权限受限、首采样、PID 重用或数据缺失时不补零。GPU 客户端变化或能量/执行时间窗口错位时暂停相关归属；只对有效完整区间积分。应用进程数据不齐时总功耗显示不可用，并标记已读取进程数。未归入应用的进程单列“其他进程（已读取部分）”，不再把整机差额分给应用。整机功耗与应用计数独立统计，合计不强制相等。

前台时长与监测时长分别显示；温度是前台时整机 CPU 温度。旧记录完整保留并标注旧算法，新算法会开始新的记录。充电、电池供电和连接电源自动分段，外接电源的长记录按天分段；仅保留最近 30 条。睡眠和锁屏时段不计入使用时长。续航估算至少需要 5 分钟有效放电及 2% 已观测电量下降。

应用功耗 CPU 能量 + GPU 归属

自动读取 CPU 内核能量和 GPU 设备能量，使用实际 GPU 执行时间归属，合并主进程及辅助进程，包含后台运行。主值为当前区间，下方为 30 秒平滑；历史按原始能量积分。按上方采样间隔更新，无需管理员授权。

GPU 部分为估算，不能保证逐应用硬件实测准确。应用进程数据不齐、GPU 客户端变化或采样窗口错位时合计不可用，并标记覆盖数；未归属和共享开销不强制分摊。

数据支持说明

CPU / 内存 / 网络 / 进程：系统原生 API。GPU：驱动公开的设备统计；逐进程 GPU 使用 IOGPU AppUsage 累计执行时间。应用功耗：CPU 内核能量 + GPU 执行时间归属估算。温度 / 风扇 / 硬件功率：SMC 只读接口，取决于机型和系统权限。实时 CPU/GPU 频率、ANE 功率和逐进程 GPU 计数器并非所有 macOS 设备都可读取。

本应用不结束用户进程、不写入 SMC、不修改风扇，也不需要联网。
